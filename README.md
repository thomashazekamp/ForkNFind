# CA400 - ForkNFind
ForkNFind is a mobile application for anyone looking to find their next place to eat. Using sentiment analysis and a recommendation system our mobile application will look to pair users up with restaurants that suit them.


We identified a problem that while working on our INTRA internships we found it challenging to be able to pick places to eat that would suit our individual tastes and preferences. Due to our busy workloads we would have benefitted from having access to an efficient application like the ForkNFind.


ForkNFind is our solution to the above mentioned problem and this will allow for a quicker informed decision from its users as to where to go for their next restaurant of choice. At the centre of our solution to this problem is to make use of two machine learning techniques: a hybrid recommendation system and sentiment analysis.
